# La sauvegarde et le délai de mise en ligne

Quand vous modifiez la galerie (ajouter une œuvre, la déplacer, changer une couleur de salle…), vos changements sont **enregistrés tout de suite**, mais ils mettent **environ une minute** à apparaître sur le site public. C'est normal, et ce guide explique pourquoi.

## Pourquoi ce délai ?

Le site n'est pas une base de données classique qui se met à jour instantanément. Chaque sauvegarde envoie vos modifications vers l'hébergement (GitHub), qui **reconstruit puis republie** automatiquement les pages du site. Cette reconstruction prend en général entre 30 secondes et une minute et demie.

## Comment suivre l'avancement ?

Juste après une sauvegarde, un petit badge **⏳** avec un décompte apparaît à côté de l'œuvre concernée :

- **⏳ + secondes** : la mise en ligne est en cours.
- **✓ publié** : c'est en ligne. Vous pouvez aller vérifier sur le site public.

## Les bons réflexes

- **Ne re-cliquez pas** sur Sauvegarder tant que le badge tourne. La sauvegarde est déjà partie : re-cliquer ne l'accélère pas et peut créer des conflits.
- Si après deux ou trois minutes le changement n'apparaît toujours pas sur le site public, **rafraîchissez la page** du site : votre navigateur garde parfois l'ancienne version en mémoire. Sur ordinateur, faites **Ctrl + F5** ; sur téléphone, tirez la page vers le bas pour la recharger.
- Votre travail n'est **jamais perdu** pendant l'attente : même si vous fermez l'onglet de l'admin, la mise en ligne continue côté serveur.

## En résumé

Sauvegardez, attendez le **✓**, puis vérifiez sur le site. Une minute de patience, et surtout pas de double-clic.
