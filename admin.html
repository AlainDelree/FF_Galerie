Connexion à GitHub

Un token GitHub permet à cet outil de sauvegarder les modifications directement sur le site. Il reste sur cet appareil uniquement.

Comment obtenir un token

  1. Allez sur github.com → votre avatar → Settings
  2. Tout en bas : Developer settings
  3. Personal access tokens → Tokens (classic)
  4. Cliquez Generate new token (classic)
  5. Note : FF Galerie admin — cochez uniquement repo
  6. Cliquez Generate token et copiez-le tout de suite
